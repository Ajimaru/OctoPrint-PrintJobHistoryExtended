# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 2.0.0a1 | :white_check_mark: |
| < 2.0.0a1  | :x:                |

## Reporting a Vulnerability

Head to the [Security tab](https://github.com/Ajimaru/OctoPrint-PrintJobHistoryExtended/security) to report vulnerabilities. Please include as much information as possible. It will be reviewed and responded to within a week.
